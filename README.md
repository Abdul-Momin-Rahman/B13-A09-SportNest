## Project Name:
SportNest

## Purpose:
SportNest is a full-stack sports facility booking management system built using the MERN stack with authentication support via Better Auth. It allows users to discover, manage, and book sports facilities like football turfs, badminton courts, swimming lanes, and tennis courts. The system simulates a real-world booking platform where users can reserve time slots, manage their facilities, and track bookings efficiently.

## Features:
